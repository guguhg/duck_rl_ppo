# 开源舵机鸭 · 深度学习补齐计划

> 定位：机器人工程师（MCU + Linux + ROS 栈），以双足小鸭 **Open Duck Mini** 为载体，把深度学习从概念走到实机。  
> 路线：**仿真训练 → 导出 ONNX → 验证通过 → 再买硬件**（不先花钱买板子）。  
> 上游项目：`apirrone/Open_Duck_Playground`（训练）+ `apirrone/Open_Duck_Mini` v2 分支（硬件/装配）+ `Open_Duck_Mini_Runtime`（部署）。

## 关键事实速查

**本机硬件**

| 项        | 值                                                |
| -------- | ------------------------------------------------ |
| CPU / 内存 | i5-11400（6C12T）/ 16 GB                           |
| GPU      | RTX 3060 Laptop **6 GB**（1024 envs 稳，4096 会 OOM） |
| 系统       | Win11 Build 26200 + WSL 3.0.3 + Ubuntu 22.04.5   |
| 安装位置     | `G:\WSL\Ubuntu-22.04\ext4.vhdx`（G 盘 100 GB 专用）   |

**自建项目 `~/duck_rl`（当前主线）**

| 项    | 值                                                                                                                                            |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 主策略  | `policy_dr1.onnx`（六方向 96.5%，抗扰动）／`policy_exp8.onnx`（直线 3.0°，无 DR）                                                                       |
| 观测契约 | **53 维** = gyro3 + gravity3 + cmd3 + q14 + qd14 + last_action14 + **yaw sin/cos 2**                                                          |
| 奖励   | **八项**：tracking_lin 2.5 / tracking_ang 0.8 / upright 0.5 / height 0.5 / heading 0.8（按 wz 门控）/ alive 0.3 / action_rate −0.01 / torque −0.0002 |
| 动作   | `ctrl = default_pos + action × 0.45`，再按 `m.actuator_ctrlrange` 逐元素剪裁                                                                         |
| 训练   | `uv run python -m duck_rl.train --num_timesteps 40000000 --num_envs 512`（约 50 分钟）                                                            |
| 验收   | `check_all_dirs.py`（六方向 2 分钟）、`check_policy_mjx.py`（单指令 + 偏航）                                                                                |

**官方参考线（已核源码，仅作对照）**

| 项    | 值                                                                                            |
| ---- | -------------------------------------------------------------------------------------------- |
| 仓库   | `apirrone/Open_Duck_Playground`，在 WSL 的 `~/Open_Duck_Playground`                             |
| 框架   | mujoco_playground（MJX）+ **Brax PPO**（JAX 栈，无 rsl_rl / 无 `.pth`）                              |
| 训练   | `uv run playground/open_duck_mini_v2/runner.py --task flat_terrain --num_timesteps 20000000` |
| 回放   | `uv run playground/open_duck_mini_v2/mujoco_infer.py -o <xxx.onnx>`                          |
| 超参坑  | `common/runner.py` 默认借的是 Berkeley Humanoid 配置，**必须手加 `num_envs`**                            |
| 硬件契约 | obs **101 维**（官方，我们是 53 维）；策略 50 Hz / PD 1 kHz；Kp=30 Kd=0（真机 Runtime，非仿真 kp=13.37）；初始姿态是蹲姿   |

**环境注意事项**

- WSL 里**不要装 NVIDIA 驱动**，驱动由 Windows 提供
- 代理：FlClash `127.0.0.1:7890`，靠 `.wslconfig` 的 `networkingMode=mirrored` 才能用；国内镜像放 `no_proxy` 直连
- 代码放 WSL 内部 `~`，**不要放 `/mnt/`**（IO 慢一个数量级）
- `astral.sh` 装 uv 会被 TLS 掐，改走 PyPI 清华源
