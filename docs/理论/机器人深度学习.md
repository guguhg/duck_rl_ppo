# 机器人深度学习技术说明

## 一、概念分层：四个维度

不同维度的概念不能横向比较"选哪个"。

| 维度 | 回答的问题 | 内容 |
|---|---|---|
| **网络结构** | 特征怎么提取 | CNN、RNN/LSTM、Transformer、点云网络 |
| **训练范式** | 策略怎么学出来 | 监督学习、模仿学习（IL）、强化学习（RL）、离线 RL |
| **模型形态** | 输入输出长什么样 | VLA（图+文→动作）、扩散策略（图+状态→动作块）、策略网络 |
| **经典方法** | 不用学习但必须有 | PID、MPC、WBC、阻抗控制、IK/FK、轨迹规划与插补 |

- **VLA 不是 RL 的一类**：前者是模型形态，后者是训练范式；VLA 可用 IL 训练，也可用 RL 微调。
- **扩散模型不是训练范式**：它是动作生成器（去噪过程），通常用 IL 训练。

## 二、分层结构

各层响应频率相差一到两个数量级，这是架构设计的第一原则。

| 层面 | 职责 | 典型技术 | 频率量级 |
|---|---|---|---|
| **感知** | 看懂环境与自身状态 | CNN 检测分割、点云网络、VLM 编码器 | 10~30 Hz |
| **决策** | 决定做什么、先做什么 | LLM 任务分解、VLM 场景理解、深度 RL、状态机 | 0.2~2 Hz |
| **技能控制** | 把决策变成动作序列 | 模仿学习/ACT、扩散策略、VLA、RL 运动策略 | 2~50 Hz |
| **伺服控制** | 跟踪轨迹、输出力矩 | PID、MPC、WBC、阻抗控制、轨迹插补 | 500 Hz~1 kHz |

学习模块集中在中间两层，伺服层以经典控制为主。

> 表里每个名词（CNN 检测分割、点云网络、VLM 编码器、LLM 任务分解、深度 RL、状态机、RL 运动策略、模仿学习、扩散策略、VLA、PID、MPC、WBC、轨迹插补）的人话解释与生活类比，见《深度学习术语通俗解释.md》第一部分。

## 三、感知层

| 技术 | 作用 | 代表模型 | 局限 |
|---|---|---|---|
| **CNN** | 分类、检测、分割、特征提取 | ResNet、YOLO、Mask R-CNN | 依赖标注，跨域泛化弱 |
| **点云网络** | 三维检测、分割、位姿估计 | PointNet++、稀疏卷积 | 吃显存，实时性受限 |
| **RNN / LSTM** | IMU、力/力矩、关节序列的时序建模 | LSTM、GRU | 长序列梯度问题 |
| **Transformer / ViT** | 多模态融合、长程依赖、开放词汇理解 | ViT、CLIP、各类 VLM | 算力需求高 |

输出应是下游可用的几何量（位姿、包围盒、掩码），不是原始特征图。

## 四、决策层

| 技术 | 作用 | 代表工作 | 局限 |
|---|---|---|---|
| **LLM** | 语言理解、任务分解、生成调用代码 | SayCan、Code as Policies | 幻觉，不理解物理可行性 |
| **VLM** | 场景语义理解、开放词汇目标定位 | CLIP、多模态大模型 | 空间精度差 |
| **深度 RL** | 导航避障、任务分配、长程决策 | PPO、DQN、SAC | 奖励设计难，样本需求大 |

输出必须是**可执行的动作原语序列**，后面要接可执行性检查：技能是否存在、参数是否越界、目标是否可达。

## 五、技能控制层

| 技术 | 数据需求 | 输出特性 | 适用 |
|---|---|---|---|
| **行为克隆 / ACT** | 几十~几百条遥操作示教 | 动作块，10~50 Hz | 结构化重复操作 |
| **扩散策略** | 与行为克隆同量级 | 多峰、平滑，推理需多步去噪 | 存在多种解法的精细操作 |
| **VLA** | 大规模多任务数据或少量本机微调 | 图+文→动作，2~10 Hz | 需要语义泛化的操作 |
| **深度 RL 策略** | 仿真千万~亿级交互步 | 策略网络小，推理快 | 行走、平衡、灵巧手等难示范技能 |
| **DMP / 示教编程** | 单条示教 | 解析式轨迹，可在线调整 | 传统工业场景 |

- **模仿学习依赖示范质量**：采集频率、标定、时序对齐、失败样本剔除，比模型选择更决定成败。
- **RL 的瓶颈是 sim2real**：接触、摩擦、背隙建不准，域随机化能缓解不能消除。
- **扩散策略的代价在推理**：多步去噪换平滑，适合低频技能层。

## 六、五种组合架构

| 组合 | 结构 | 典型需求 | 主要代价 |
|---|---|---|---|
| **① 慢思考 + 快思考** | 大模型决策 → 经典控制/RL 执行 | 自然语言、长程任务 | 层间接口设计复杂 |
| **② IL 初始化 + RL 微调** | 技能层内部两阶段 | 快速学会精细操作 | 依赖示范质量，需仿真环境 |
| **③ 经典控制 + 学习补偿** | PID/MPC + RL 残差或扰动预测 | 极高稳定性 | 学习模块接入需谨慎 |
| **④ 端到端 VLA** | 图+文直接输出动作 | 通用端到端架构 | 实时性、安全性、数据量门槛 |
| **⑤ LLM 编排 + 技能库** | LLM 只调度，不控关节 | 可扩展可组合系统 | 受技能库覆盖度限制 |

产业界最稳的是 **①**，控制层内部最常见 **②③**，**④⑤** 属前沿与系统级方案。成熟系统常以 ① 为骨架、⑤ 做编排、② 做技能。

## 七、按机器人形态看技术分布

差异不在"用不用 AI"，而在**精度要求与建模难度**。

| 层面 | 工业机械臂 | 双足人形 | 四足机器狗 |
|---|---|---|---|
| **感知** | 缺陷检测、6D 位姿估计、焊缝跟踪 | VIO/SLAM、可通行区域、人体检测 | 地形分割、语义高程图 |
| **决策** | PLC/上位机 + 状态机，换型靠配方与工艺参数切换 | LLM/VLA 任务分解 | Nav2 + 学习型局部避障 |
| **运动生成** | **MoveIt 线与 VLA 线并行** | RL 行走 + WBC，模仿学习做操作 | RL 学步态 |
| **伺服** | 位置/力矩环 250 Hz~1 kHz | 关节 PD 1 kHz + WBC | 关节 PD 1 kHz + 策略 50 Hz |

### 工业机械臂：MoveIt 线与 VLA 线

感知层深度学习用得很深（散乱抓取的 6D 位姿估计与抓取质量评估、缺陷检测、焊缝跟踪）。运动生成有两条并行技术线：

| | **MoveIt 线** | **VLA 线** |
|---|---|---|
| **输入** | 目标位姿 + 场景模型 | 图像 + 语言指令 + 关节状态 |
| **产出** | 无碰撞路径 + 时间参数化 | 关节轨迹或动作块 |
| **适合** | 结构化、重复、高精度场景 | 换型频繁、非结构化、语义驱动场景 |
| **长处** | 可复现、可审核、约束完整、节拍稳定 | 免建模、泛化好、省掉位姿估计等中间环节 |
| **投入** | 场景建模与目标配置 | 数据采集与训练 |

**两条线是分工而非替换**：几何已知、流程固定的任务走 MoveIt 线，品种常换、来料姿态随机的场景走 VLA 线。两者可汇到同一执行链，碰撞与限位由下游统一校验，因此能并存、能逐场景切换。

VLA 线的四个落点：换型免重新示教、异常状态判断（卡料、掉件、错料）、粗定位（末端进视野后交给视觉伺服）、自然语言下任务。工程上要解决三件事：**节拍**（动作分块 + 异步推理）、**成功率**（失败检测与重试）、**可追溯**（记录观测与动作便于复盘）。

### 双足人形与四足机器狗

- **双足**：VIO/SLAM 定位，LLM/VLA 做任务分解；行走靠 RL（Isaac Lab 并行训练 + 域随机化），WBC 做全身多任务分配，操作多用模仿学习（示范比设计奖励容易）；关节 PD 1 kHz，策略推理 50 Hz，中间靠插值衔接。
- **四足**：LiDAR 建高程图，分割网络做地形分类；步态以 RL 为主，也有 MPC 加凸优化、模型基控制等路线并存；策略输出 50 Hz 关节目标，底层 PD 1 kHz 跟踪。
- **共同特点**：自由度多、接触频繁、动力学建不准，学习的收益集中在关节层与地形适应。

### 三条判断依据

1. **精度要求决定学习的落点**：要求 0.02 mm 时适合放在目标生成与感知，允许厘米级时可直接输出关节目标。
2. **模型准不准决定用不用学**：模型可靠时用模型驱动，模型不可靠时用数据补。
3. **失败代价决定验证方式**：人机共处必须仿真先行，sim2real 成为核心工序。

## 八、常见误区

1. **忽略频率落差**：10 Hz 的推理输出直接接 1 kHz 伺服会出现台阶与抖动，中间必须有插补与平滑。
2. **让学习模块进安全链**：安全判断需要确定性，应与学习输出分离，由独立环节校验与限幅。

## 九、术语速查

| 缩写 | 全称 | 含义 |
|---|---|---|
| **VLA** | Vision-Language-Action | 图+文→动作的多模态模型形态 |
| **IL / BC** | Imitation / Behavior Cloning | 从示范学；BC 是最朴素的监督式版本 |
| **RL** | Reinforcement Learning | 用奖励信号试错学策略 |
| **ACT** | Action Chunking with Transformers | 一次预测一段动作，减少累积误差 |
| **DMP** | Dynamic Movement Primitives | 解析式示教轨迹表示，可在线调整 |
| **MPC / WBC** | Model Predictive / Whole-Body Control | 滚动时域优化 / 多任务优先级全身控制 |
| **VIO / SLAM** | Visual-Inertial Odometry / 定位建图 | 里程计与地图构建 |
| **sim2real** | Simulation to Reality | 仿真训练、真机部署 |
